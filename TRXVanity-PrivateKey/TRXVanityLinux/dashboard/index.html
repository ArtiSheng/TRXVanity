实时日志怎么看
SECURITY

确认该任务是 PUBLIC_ONLY：云端只有公钥，没有本地基准私钥。

READY

GPU 初始化完成；最后的 lanes 是每批并行检查的候选槽数，不是 CPU 线程数。

SEARCHING

已经开始搜索指定后缀；这里应显示当前任务 ID 和 88888888。

PROGRESS

依次是协议版本、任务 ID、累计尝试数、从启动至今的平均速度、运行秒数。

RESULT

命中地址和公开偏移已产生；本地监控器会保存完整结果，偏移本身不是私钥。

STOPPED / ERROR

任务被停止，或在请求、自检、GPU 初始化、搜索阶段发生错误。

页面日志只展示远端完整日志的最后 80 行，所以稳定运行后通常几乎都是 PROGRESS。

回传保障边界

本地监控服务通常每 2 秒拉取一次，浏览器关闭不影响。网络恢复后会自动重连补取，一次失败的 SSH 超时可能使补取延后到约 2–12 秒；但如果 Mac 离线期间云实例被直接销毁，点对点传输无法保证找回尚未同步的结果。
