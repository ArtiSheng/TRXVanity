# Legacy Web Source Archive

[中文说明](README.zh.md)

This directory only keeps the old web files. It is not part of the native macOS app build or run.

- `app/page.tsx`: old page structure (JSX/HTML)
- `app/layout.tsx`: old HTML outer layout
- `app/globals.css`: old full CSS

Old workers, web crypto, and historical build config are archived here as-is, for reference only.
